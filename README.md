Création d’un projet Maven compatible JEE avec JPA et Hibernate.
Configuration de l’unité de persistance avec persistence.xml pour une base H2 en mémoire.
Modélisation des entités Salle et Utilisateur avec annotations JPA.
Implémentation d’une DAO générique et de DAO spécifiques sans EJB.
Gestion manuelle des transactions et du contexte de persistance.
Création d’un service métier simple pour orchestrer les opérations.
Écriture de tests unitaires avec JUnit pour valider la persistance.
Gestion des erreurs et bonnes pratiques pour la robustesse.
Utilisation avancée de requêtes JPQL pour des recherches complexes.
